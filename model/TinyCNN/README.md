# TinyCNN

A small quantized convolutional network for testing ExecuTorch inference on
Cortex-M targets. It accepts a 16 x 16 RGB image and produces logits for ten
classes.

The application image contains neither the `.py` source nor the `.pt2` file.
Model conversion lowers the selected input to a `.pte` program, emits it as a
const C byte array, and links that array into the application image (normally
in read-only flash).

## TinyCNN integration test

The default integration test loads a TinyCNN program with one `forward`
method and validates its ten output logits.

- `TinyCNN.py` defines the floating-point model consumed directly by the MLOps
  workflow.
- `TinyCNN.pt2`, generated by `quantize_TinyCNN.py`, is an already exported and
  quantized representation of the same model.

The test runners are provided for
[CMSIS M](../../cmsis-m/src/app_main.cpp),
[CMSIS U55](../../cmsis-u55/src/app_main.cpp),
[CMSIS U85](../../cmsis-u85/src/app_main.cpp),
[Zephyr M](../../zephyr-m/src/executorch_test.cpp),
[Zephyr U55](../../zephyr-u55/src/executorch_test.cpp), and
[Zephyr U85](../../zephyr-u85/src/executorch_test.cpp). This test is selected
by default in each solution.

See [model conversion](../../model_conversion/README.md) for conversion
details.

## Multiple-method integration test

`TinyCNNMultiple.pt2`, generated by `quantize_TinyCNNMultiple.py`, is an
integration-test fixture containing INT8 image `filter` and `classify` methods.
The methods run sequentially, not in parallel: `filter`
completes first, then its output is passed to `classify`. The resulting logits
are checked against a fixed reference.

The test runners are provided for
[CMSIS M](../../cmsis-m/src/executorch_multiple_test.cpp),
[CMSIS U55](../../cmsis-u55/src/executorch_multiple_test.cpp),
[CMSIS U85](../../cmsis-u85/src/executorch_multiple_test.cpp),
[Zephyr M](../../zephyr-m/src/executorch_multiple_test.cpp),
[Zephyr U55](../../zephyr-u55/src/executorch_multiple_test.cpp), and
[Zephyr U85](../../zephyr-u85/src/executorch_multiple_test.cpp).

For a CMSIS solution, select these three items together:

1. `TinyCNNMultiple.pt2` in `mlops.model.input`.
2. The matching `cmsis-*-multiple.cproject.yml` project.
3. The matching `cmsis-*-multiple.Debug` target image.

For Zephyr, select `TinyCNNMultiple.pt2` and enable
`CONFIG_EXECUTORCH_MULTIPLE_TEST`.
